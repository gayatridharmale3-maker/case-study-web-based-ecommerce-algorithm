# 🛒 Amazon Clone with Algorithms

## 📌 Project Overview
This project is a simple Amazon-like E-commerce web application developed using HTML, CSS, and JavaScript.  
It demonstrates how basic **Data Structures and Algorithms (DSA)** are used in real-world systems like Amazon.

---

## 🚀 Features
- 🔍 Product Search
- 🛍️ Product Display
- 🛒 Add to Cart
- ❌ Remove from Cart
- 💰 Total Price Calculation
- 🖼️ Product Images & UI Design

---

## ⚙️ Algorithms Used

### 1. 🔍 Linear Search
Used to search products based on user input.

**Method Used:** `filter()`

---

### 2. 🛍️ Array Traversal
Used to display products dynamically.

**Method Used:** `forEach()`

---

### 3. 🛒 Insertion (Add to Cart)
Adds products to cart.

**Method Used:** `push()`

---

### 4. ❌ Deletion (Remove from Cart)
Removes products from cart.

**Method Used:** `splice()`

---

### 5. 💰 Summation Algorithm
Calculates total cart value.

**Logic:** `total += price`

---

## 🧾 Data Structure Used
- **Array**
  - Stores product list
  - Stores cart items
